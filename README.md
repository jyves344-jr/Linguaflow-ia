# LinguaFlow AI MVP

## Run locally
1. Install Node.js 20+.
2. Open this folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Included
- Responsive landing page
- Language and level selection
- Pricing section
- Student dashboard
- Lesson/quiz UI
- Basic AI-tutor chat UI (demo/local state)
